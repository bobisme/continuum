# The literal-kind corpus of the no_std structure rules (cr-35ujnx). Each case is a
# snippet appended to a pack's real `lib.rs`. `extern` is the verdict of the `extern`
# rule alone; `structure` is the verdict of all the structure rules. An `-inside` case
# puts `extern crate std` inside one literal kind, where it is text, not a declaration.
# A `-beside` case uses that literal kind to hide a real `extern crate std as s;` from a
# scan that lexes the literal wrongly, and the real declaration must still be caught.
# The Rust twin (INV-015) runs every case; each case is also a GOV-4-13 fixture named
# `gov4-13-lexer-<name>`, which runs the Python twin.
