G0 exists to kill seductive architecture before it ossifies. A failed load-bearing spike blocks interface freeze.

The freeze-blocking subset is DX-01–03, 10, 12, 13, 14 (plan §22): a failed or unexecuted freeze-blocking item blocks interface freeze. Re-homed items block their target gates instead; DX-04, 05, 07, and 08 contributed Phase A artifact-shape spikes and are re-homed to the gates owning their engines (plan §22). Plan §0.3's counts derive from this table. ## Promotion rule

A spike may become architecture only when it has:

1. a precise semantic claim;
2. a reference implementation or checker;
3. adversarial mutations;
4. deterministic artifacts;
5. a baseline;
6. a failure policy;
7. a path to independent evidence.

A visually impressive demo is not a pass condition.
